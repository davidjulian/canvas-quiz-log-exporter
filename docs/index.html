CHOOSE WHAT YOUR FILES RETAIN

Two export modes. One simple workflow.

The mode controls file contents. Choose the option appropriate for your institution’s data handling rules.

01DEFAULT

Coded logs

Random IDs in place of student names, with a separate private lookup table.

  • Retains the displayed event wording and elapsed times.
  • Omits Began and Finished calendar dates and clock times.
  • Replaces reviewed student names and recognizable email, web and IPv4 addresses.
  • Creates coded-logs.zip and a separate private/name_key.csv.

Review coded text before sharing. Other identifying details can remain.

02IDENTIFIED RECORDS

Named logs

Student names and original dates and times, for use in an authorized environment.

  • Retains student names in filenames and file headers.
  • Keeps the original dates, times and displayed event text.
  • Performs no student coding or identifier removal.
  • Creates named-logs.zip, with no name key or ID/key confirmation.

Use only storage and services authorized for identified student records.

DOWNLOAD. INSTALL. OPEN.

Start on your own computer.

Have Python 3.10 or newer and Edge or Chrome installed. Setup downloads the app’s Python dependency once.

  1. 1

    Download and extract

    Download the ZIP and extract it completely. Open the canvas-quick-capture folder. Don’t run files inside the ZIP.

  2. 2

    Install once

    Double-click Install.cmd. It prepares a local Python environment. You don’t need to type commands for normal use.

  3. 3

    Open the exporter

    Double-click Start App.cmd. The local interface opens in your browser. Choose your Canvas URL, output folder and export mode.

THEN, IN CANVAS

Build → Moderate → Download

Sign in to Canvas in the separate app browser window. Open your completed New Quiz, then go to Build → Moderate. Set your filters and students per page, and let the list load.

Return to the app to find the logs and review the student names. Start, check the first downloaded file, then confirm to collect the remaining displayed logs. In coded mode, check the ID in the private name key; named mode needs no key.

Full instructions and troubleshooting ↗
i

One Moderate page per run.

The app downloads the View Log controls currently displayed. It does not advance student or event pagination, reveal hidden attempts, scroll virtual lists or expand details. Check each downloaded file for completeness.

SEPARATE FILES. CAREFUL HANDLING.

Keep the key with you.

In coded mode, names and the ID-to-name key stay in private/, alongside full original captures and capture details. They are excluded from the coded download ZIP. Keep this folder restricted to authorized users.

Separating identifiers from reviewed coded logs may allow the coded output to be handled as Sensitive rather than Restricted data where institutional rules permit. It does not automatically change the classification or guarantee anonymity.

You decide what can be shared.

Review free text for remaining identifying details and follow all applicable institutional privacy, data handling and FERPA rules. Use only services approved for the resulting classification.

The app performs no analysis and never automatically uploads records to AI. Canvas still uses its normal institutional sign-in and services. Named logs retain identified student records and require an authorized environment.
