Canvas Quiz Log Exporter

A free local tool for instructors to download the displayed event text from Canvas New Quizzes logs. It collects logs across recognized numbered Moderate student pages and produces a local descriptive focus-event summary.

This website provides software downloads and instructions. The app runs locally on your computer; student records are not uploaded to this website or GitHub.

Downloads

Version 0.13.1. Python 3.10 or newer and an installed copy of Google Chrome or Microsoft Edge are required. Safari cannot be used as the dedicated Canvas browser.

  • Windows ZIP — Windows 11 or later.
  • macOS ZIP — macOS 14 (Sonoma) or later, Intel or Apple silicon.

Release notes and previous versions · Source code and documentation

This is a Python application with a local browser interface, rather than a standalone executable. The Mac scripts are not a signed or notarized application. Follow your institution’s software installation rules.

Installation

Install an institution-approved Python 3.10 or newer, or use the Python downloads. Install Chrome or Edge if needed. Internet access is required during setup.

Windows

  1. Download the Windows ZIP and extract the entire folder.
  2. Open the extracted folder and double-click Install.cmd. Wait for setup to finish.
  3. Double-click Start App.cmd. The local app opens in your default browser.

macOS

  1. Download the macOS ZIP and extract the entire folder.
  2. Open the extracted folder and double-click Install.command. A Terminal window opens for setup.
  3. When setup finishes, double-click Start App.command. Leave its Terminal window open while using the app.

If a Mac launcher opens as text or lacks permission, see the Mac troubleshooting instructions. If institutional security blocks the software, consult your IT support. No administrator access is needed by the app’s setup scripts.

The app interface can open in your usual browser. The separate Canvas window uses Chrome by default on Mac and Edge on Windows; either supported browser can be selected in the app.

Using the app

  1. Enter your Canvas address (UF is the default), choose an output folder and select an export mode. An optional Quiz name or folder label identifies the run folder; the app adds a date and unique suffix. Leave it blank for the default folder name.
  2. Select Open Canvas. Sign in yourself in the separate browser. Open the completed New Quiz, then go to Build → Moderate. Set the desired filters and students per page, and wait for the list to load.
  3. Return to the app, select I’m on Moderate — find logs, wait while the app scans the numbered student pages, then review the combined names and count and start collection. Do not change Canvas filters, sorting or page size after review.
  4. Compare the first downloaded log with Canvas, including its final event. In coded mode, also check the ID against the private name key using the button provided.
  5. Confirm the check to collect the remaining displayed logs. Leave the separate Canvas window alone during collection.
  6. Use Open output folder to find the text files and export ZIP. If you selected Keep Canvas open for another quiz, open the next quiz in that window, change the folder label and select Use open Canvas for a new run. Otherwise Canvas closes after collection. If the quiz/folder label is unchanged for a new run, choose Change label or explicitly confirm Use same label before continuing. Select Quit local app when finished.

Export modes

Coded logs (default)

Files use random IDs. Reviewed names and recognizable email, web and IPv4 addresses are replaced. Start and finish calendar dates and clock times are omitted; elapsed times and event wording are retained.

The separate private/name_key.csv maps IDs to names. The private/ folder also contains original captures. These files are excluded from coded-logs.zip. Other identifying details may remain in coded text, so review it before sharing.

Named logs

Files retain student names, original dates, times and event text. This mode creates no coded IDs or private name key and requires no ID/key confirmation. Use only environments authorized for identified education records.

Local event summary

New collections produce a sortable table with student name, total elapsed time, the number of Stopped viewing events, average away time, total paired away time, percentage of elapsed time away and longest paired away period. The average uses only unambiguous Stopped viewing → Resumed pairs. Missing returns, consecutive stops and timestamp problems are flagged rather than assigned assumed durations. Total and longest away time use valid pairs only. Percentages are flagged when the attempt duration is unverified. Each attempt remains a separate row.

Elapsed time comes from a recognized submission event when available. Otherwise it uses a readable last timed event, labeled as an estimate. Earlier invalid timestamps do not discard that elapsed value, but can leave away durations unavailable. An unreadable final event or contradictory timing can still leave elapsed time unavailable. Elapsed time can include long breaks and does not measure active working time. Unloaded events can affect every measurement.

The named CSV is saved at private/event_summary.csv, alongside calculation notes. It stays outside the sharing ZIP even in coded mode and requires protection as identified student data. Select Open named summary CSV after collection finishes or stops. Earlier exports are not imported.

These are descriptive measurements, not a misconduct detector. They cannot identify another website or application or establish ChatGPT use. Instructure advises against using quiz logs to validate academic integrity.

Privacy and limitations

Output, original captures and browser sign-in state remain on your computer or the storage you select. The app requests no Canvas API token and sends no records to AI services. Canvas uses its normal institutional sign-in and connections.

Coding does not guarantee anonymity, change a data classification or certify FERPA compliance. The user is responsible for following institutional privacy, storage, disclosure and retention rules. Keep identifying originals and the private name key protected. Share only locally reviewed files through services approved for their resulting classification.

A run scans recognized numbered Moderate student pages using the current filters, combines their names for one review, and saves one folder, ZIP and summary. Ambiguous page controls, repeated pages or changed lists stop collection and preserve completed files. Hidden attempts, virtual lists, collapsed details and additional pages inside event logs are not loaded automatically. The app targets English New Quizzes layouts with logs opening in the same tab. Verify the downloads locally.

Page focus events alone cannot establish LLM use or misconduct.
