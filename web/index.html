ABOUT THIS APP

Canvas Quiz Log Exporter

Download the displayed event text for each View Log on one Canvas New Quizzes Moderate page. The app runs on your computer and keeps the original event wording and elapsed times. A separate local table summarizes recorded focus events; it does not classify students or misconduct.

The named summary is saved separately at private/event_summary.csv, with definitions at private/summary_method.txt. These files are not added to the log sharing ZIP. It summarizes only new downloads, including completed files from a stopped run; it does not import prior exports. Unreadable or ambiguous events are flagged, and summary failure does not stop the text downloads.

How it works

  1. Choose your Canvas address, local output folder and export mode.
  2. Sign in to Canvas, open the completed quiz, and go to Build → Moderate.
  3. Review the student names, then start. Check the first downloaded log against Canvas. In coded mode, also check its ID in the private name key.
  4. Confirm the first log to download the remaining displayed logs. Find them in logs/ and the ZIP for your selected mode.

Separate coded logs and identifying records

Coded logs (default): Each log receives a random ID. Student names and the ID-to-name lookup table are kept separately in private/name_key.csv. The private/ folder also holds full original captures and capture details, which can contain identifying information. These private files are excluded from coded-logs.zip.

Coded logs omit start and finish calendar dates and clock times, and replace reviewed student names and recognizable email, web and IPv4 addresses. Other identifying information can remain in free text, so check the coded files before sharing.

Named logs: Download student names, original dates and times, and the displayed event text in named files and named-logs.zip. No student coding, private name key or ID/key confirmation is used. Use this mode only in storage and services authorized for identified education records and their required classification.

Privacy and data classification

Separating identifying records from reviewed coded logs may allow the coded output to be handled as Sensitive rather than Restricted data, where your institution’s classification and de-identification rules permit. This separation does not automatically change the classification or guarantee anonymization. The private key and original records must retain the protections required by your institution.

You are responsible for reviewing the output and following all applicable institutional privacy, data handling and FERPA rules. Nothing is automatically uploaded to AI or another service. Canvas still uses its normal institutional sign-in and connections.

Use only services approved for the data’s resulting classification. Reviewed coded logs may be eligible for tools approved for Sensitive data when your institution permits; keep identifiable originals and the name key in an environment approved for their required classification.

One Moderate page per run. Hidden attempts, additional student or event pages, scrolling and collapsed details are not collected automatically. Focus events alone cannot establish misconduct.
