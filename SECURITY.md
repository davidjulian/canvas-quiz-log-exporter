# Privacy and security

Use only an authorized Canvas account. This app runs locally; do not publicly host its server or forward its port.

Never include real student logs, name keys, identifying screenshots, browser profiles, cookies, tokens, session links, or restricted records in GitHub issues or pull requests. Use invented examples and counts or fixed error categories when reporting problems.

Coded output is not guaranteed anonymous. Review its free text before sharing, and keep the private key and full captures protected. Named mode performs no coding or identifier removal and retains student names, dates and times. Choosing a mode does not authorize a storage location, change a data classification, encrypt files or certify FERPA compliance. Follow your institution's privacy, security, disclosure and retention rules.

Report security issues using GitHub private vulnerability reporting if enabled for this repository; do not disclose sensitive records in a public issue.
